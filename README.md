This repository automatically syncs Minecraft mods and datapacks directly to the server using GitHub Actions over a secure Tailscale connection.

---

## 📁 Repository Structure

* `mods/` – Put all mod files (`.jar`) here.
* `datapacks/` – Put all datapack folders or `.zip` files here.

---

## 📥 Adding Mods & Datapacks

1. Place your mod files directly into the **`mods/`** folder.
2. Place your datapacks into the **`datapacks/`** folder.
3. Commit and push your changes (or open a Pull Request).
4. The GitHub Action will automatically handle uploading them to the server.

---
